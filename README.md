# 🧽 스펀지 메모

> 까먹기 전에, 쓱 하나 남겨두기

정신없을 때 할 일을 까먹지 않으려고 만든 **나만의 메모 · 할 일 웹앱**이에요.
설치나 로그인 없이 브라우저에서 `index.html` 하나만 열면 바로 쓸 수 있어요.

## ✨ 주요 기능

### 📋 할 일 목록
- 적어둔 기록을 **급한 순서대로 묶어서** 보여줘요.
  🔴 날짜 지남 → 📅 오늘 → 🗓️ 이번 주 → ❗ 중요(★★★) → 📝 나머지
- 🫧 **바다 보기**로 바꾸면 기록이 물고기처럼 둥둥 떠다녀요.
- 카테고리(업무 · 육아 · 자기계발 · 창작 · 기타 등)와 중요도(★1~3)를 정할 수 있어요.

### 📅 날짜 자동 인식
메모에 날짜를 적으면 알아서 일정으로 인식해서 달력에 표시해줘요.

```
8/25 병원
8월 25일 14:00 미팅
2026-09-01 오후 3시 치과
```

### ✅ 완료함과 되돌리기
- 동그라미를 눌러 완료하면 **완료함**에 쌓이고, "오늘 N개 해냈어요"로 보여줘요.
- 완료나 삭제를 잘못 눌러도 **되돌리기**로 바로 살릴 수 있어요.

### 🎯 포커스 모드
- 지금 할 일 **딱 하나만** 골라서 타이머와 함께 집중해요.
- 날짜가 지났거나 오늘인 일, 중요한 일부터 먼저 추천해줘요.

### ☰ 도구함
| 도구 | 설명 |
|---|---|
| 📊 미니 현황판 | 큰 프로젝트별 진행률(%)과 이번 주에 손댄 여부 |
| 💰 간단 가계부 | 고정지출 · 수입 · 통장 잔액 · 지출 내역 |
| 🪜 사다리타기 | 고민될 때 돌려보는 미니 게임 |
| 💾 백업 / 복원 | JSON 파일로 내보내고 다른 기기에서 가져오기 |
| 🔗 바로가기 | 자주 가는 사이트 모음 (직접 추가 가능) |

## 🔗 바로가기 추가하기

`index.html`에서 `자주 가는 사이트를 여기에 추가하세요`를 검색하고, 그 아래에 한 줄을 추가하면 도구함에 나타나요.

```html
<a class="tool" href="https://example.com" target="_blank" rel="noopener noreferrer"><span class="ic">⭐</span><span class="lb">내 사이트</span></a>
```

카테고리를 바꾸고 싶으면 `const CATEGORIES`를 찾아 이름과 이모지를 고치면 돼요.

## 🚀 사용 방법

1. 이 저장소를 내려받거나 GitHub Pages 주소로 접속해요.
2. 브라우저에서 `index.html`을 열어요.
3. 입력창에 적고 **Enter**를 누르면 바로 추가돼요. 줄바꿈은 **Shift + Enter**예요.

| 단축키 | 동작 |
|---|---|
| `Enter` | 기록 추가 |
| `Shift + Enter` | 줄바꿈 |
| `Esc` | 열린 창 닫기 |

## 💾 데이터는 어디에 저장되나요?

- 모든 기록은 **내 브라우저(localStorage)에만** 저장돼요. 서버로 보내지 않아요.
- 그래서 브라우저나 기기가 바뀌면 기록이 보이지 않아요. **도구함 → 💾 백업**으로 파일을 저장해두세요.
- 7일 넘게 백업을 안 하면 화면에 알림이 떠요.

## 📁 파일 구성

```
├── index.html   # 스펀지 메모 (파일 하나로 동작, 마스코트도 코드로 그림)
└── README.md
```

## 🛠️ 만든 방식

- 순수 HTML · CSS · JavaScript (라이브러리나 빌드 과정 없음)
- 마스코트는 직접 그린 SVG예요. 통통 튀고 가끔 눈을 깜빡여요.
- 모바일 화면도 지원해요.
